Open the question relevant to your architecture.

Are root keys stored permanently?+

The Dynamic PUF design recovers associated root material from physics and checkpoint data rather than keeping the root key permanently in NVM.

How much checkpoint data is needed?+

The current product description uses approximately 200 bytes of checkpoint data per recoverable root. Exact implementation figures depend on the target.

Can the PUF move to another process?+

The logic-based PUF cells are redesigned and validated for the target node and foundry. The ACC method remains process independent.

What completes a full Root of Trust?+

IIST can combine Dynamic PUF with cryptographic primitives, key management, lifecycle control, secure boot, update, and other security-engine functions.
